\subsection{Область допустимых значений крутящего момента на выходном валу передаточного механизма}

Согласно требованиям технического задания максимальный крутящий момент на выходном валу передаточного механизма не должен превышать
\[
|M_m(t)| \le 150 \text{ Н}\cdot\text{м}.
\]

Для определения момента на выходном валу воспользуемся выражением, полученным при составлении математической модели механической части:
\begin{equation}
    M_{\text{м}}(t)
    =
    b
    \left(
        \dot{\varphi}_{\text{рпр}}(t)
        -
        \dot{\varphi}_{\text{м}}(t)
    \right)
    +
    c
    \left(
        \varphi_{\text{рпр}}(t)
        -
        \varphi_{\text{м}}(t)
    \right).
\end{equation}

Для каждой точки области устойчивости, вычислялось максимальное значение момента
\[
|M_m|_{\max}=\max_t |M_m(t)|.
\]

Полученные значения были использованы для построения трёхмерной поверхности зависимости максимального момента от коэффициентов регулятора \(k_{\text{п}}\) и \(k_{\text{и}}\). При этом поверхность была ограничена сверху плоскостью
\[
|M_m|_{\max}=150 \text{ Н}\cdot\text{м},
\]

что позволяет выделить область параметров, удовлетворяющих требованиям технического задания.

На рисунке~\ref{fig:pdf/moment_region_3d} пунктирной линией на плоскости \(k_{\text{п}}-k_{\text{и}}\) показана граница области устойчивости, а цветной поверхностью — изменение максимального значения момента внутри данной области.

\screenshot[0.8]{pdf/moment_region_3d}{Зависимость максимального крутящего момента $|M_m|_{\max}$ от коэффициентов $k_{\text{п}}$ и $k_{\text{и}}$}

Из полученного графика видно, что при увеличении коэффициента интегральной составляющей \(k_{\text{и}}\) максимальное значение момента возрастает значительно быстрее, чем при изменении коэффициента \(k_{\text{п}}\). Вблизи границы устойчивости часть устойчивых режимов перестаёт удовлетворять ограничению
\[
|M_{\text{м}}|_{\max} \le 150 \text{ Н}\cdot\text{м}.
\]
