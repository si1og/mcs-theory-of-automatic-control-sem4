\subsection{Передаточная функция обратной связи}

В зависимости от структурной схемы цепи обратной связи формируются уравнения сигнала управления. Исходная схема представлена на рисунке~\ref{fig:feedback_scheme}.

\begin{figure}[H]
    \centering
    \input{tex/graphics/figures/control_scheme}
    \caption{Схема обратной связи}
    \label{fig:feedback_scheme}
\end{figure}

Сигнал обратной связи по координате ротора двигателя определяется выражением
\begin{equation}
    q_{\text{р}}
    =
    \frac{k}{i}\varphi_{\text{р}}
    =
    k\varphi_{\text{рпр}},
\end{equation}
где
\begin{equation}
    \varphi_{\text{рпр}}
    =
    \frac{\varphi_{\text{р}}}{i}
\end{equation}
--- приведенный угол поворота ротора двигателя.

Сигнал обратной связи по координате выходного звена:
\begin{equation}
    q_{\text{м}}
    =
    k\varphi_{\text{м}}.
\end{equation}

Тогда сигналы рассогласования имеют вид
\begin{equation}
    \psi_{\text{р}}
    =
    \varphi_{\text{рпр}}-\varphi^*,
\end{equation}

\begin{equation}
    \psi_{\text{м}}
    =
    \varphi_{\text{м}}-\varphi^*.
\end{equation}

В соответствии с вариантом используется ПИ-регулятор, содержащий пропорциональное звено по сигналу $\psi_{\text{р}}$ и интегральное звено по сигналу $\psi_{\text{м}}$:
\begin{equation}
    W_{\text{р}}(p)=k_{\text{п}},
    \qquad
    W_{\text{м}}(p)=\frac{k_{\text{и}}}{p}.
\end{equation}

По структурной схеме системы сигнал управления определяется выражением
\begin{equation}
    u
    =
    -
    k_{\text{п}}k
    \left(
        \varphi_{\text{рпр}}-\varphi^*
    \right)
    -
    \frac{k_{\text{и}}}{p}
    k
    \left(
        \varphi_{\text{м}}-\varphi^*
    \right).
\end{equation}

Умножим обе части уравнения на оператор $p$:
\begin{equation}
    pu
    =
    -
    k_{\text{п}}kp
    \left(
        \varphi_{\text{рпр}}-\varphi^*
    \right)
    -
    k_{\text{и}}k
    \left(
        \varphi_{\text{м}}-\varphi^*
    \right).
\end{equation}

Раскрывая скобки, получим
\begin{equation}
    pu
    =
    -
    k_{\text{п}}kp\varphi_{\text{рпр}}
    +
    k_{\text{п}}kp\varphi^*
    -
    k_{\text{и}}k\varphi_{\text{м}}
    +
    k_{\text{и}}k\varphi^*.
\end{equation}

Перейдем к обозначению производных по времени и учтем, что
\[
    \varphi^* = \text{const}.
\]

Тогда уравнение управления принимает вид
\begin{empheq}[box=\fbox]{equation}
    \dot{u}
    +
    k_{\text{п}}k\dot{\varphi}_{\text{рпр}}
    +
    k_{\text{и}}k\varphi_{\text{м}}
    =
    k_{\text{и}}k\varphi^*.
\end{empheq}
